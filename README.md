# Внутренняя страница WebCreative Studio

`index.html` — одна страница, содержимое которой зашифровано (AES-GCM, ключ
выводится из пароля функцией PBKDF2-SHA256). В исходном коде лежат только
случайные байты; текст расшифровывается в браузере после ввода пароля.

Страница собирается автоматически, руками не правится. Пароль задаёт
владелец и здесь не хранится.
