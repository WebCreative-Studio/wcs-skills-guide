# Инструктаж «Какой скилл брать»

Одна страница для сотрудников: что написать в задаче и какой скилл подхватит
работу. Разделы — разработка, каталог и товары, SEO, отчёты, продажи, финансы,
серверы и доступы, внутренняя кухня.

Страница опубликована через GitHub Pages. Её содержимое зашифровано
(AES-GCM, ключ выводится из пароля функцией PBKDF2-SHA256), поэтому в
исходном коде видны только случайные байты: без пароля читать нечего.
Расшифровка происходит в браузере после ввода пароля.

Пароль задаёт владелец. Он не хранится ни в этом репозитории, ни в истории
команд.

## Что здесь лежит

- `index.html` — собранная страница целиком, вместе с зашифрованным текстом.
  Руками не правится: он собирается заново.

## Как пересобрать и выложить

Исходники инструктажа (текст разделов, разбивка скиллов по направлениям и
сборщик) лежат в репозитории `wcs-skills`, папка `library/skills-guide`.
Оттуда же запускается публикация. Порядок — в её `README.md`.

Пересобирать нужно после: появления или снятия скилла, правки текста
инструктажа, смены пароля.
